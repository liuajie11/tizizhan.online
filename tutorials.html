DESKTOP TUTORIAL

Windows 平台机场客户端配置教程

Windows 10 / 11 兼容 推荐首选

Windows 是目前协议支持最全面、操作最灵活的桌面系统。推荐优先使用开源现代的 Clash Verge Rev 或轻量经典的 v2rayN。

★ 推荐客户端：Clash Verge Rev 备选客户端：v2rayN 内核支持：Mihomo (Clash Meta) / Xray
01

可信来源下载与安装

请认准开发者官方 GitHub Release 页面下载，切勿通过普通搜索引擎点击带有“赞助商/广告”字样的仿冒二次打包站点。推荐下载 .msi 安装包或便携版 .zip，安装时若出现 SmartScreen 提示，点击“更多信息”并选择“仍要运行”。

02

导入机场订阅链接

进入你在机场后台（如 机场推荐收录目录 中的任意服务）的仪表盘，找到“一键导入订阅”或“复制订阅链接 (Clash/通用)”。在客户端左侧菜单点击【订阅 (Profiles)】，将链接粘贴至顶部输入框，点击【保存并下载】，等待提示导入成功。

03

选择节点与开启系统代理

点击客户端左侧【代理 (Proxies)】进入节点列表，右上角路由模式保持为【规则 (Rule)】（国内网站直连不耗流量，海外网站自动走节点）。点击展开节点分组，选择延迟低且稳定的节点，最后在【设置】或主界面打开【系统代理 (System Proxy)】开关即可连接上网。

04

进阶模式：开启 TUN 虚拟网卡 & 开机自启

如果需要让游戏、命令行终端 (CMD/PowerShell/Git)、UWP 应用或局域网软件全量走代理，请在设置中开启【TUN 模式】。同时建议勾选【开机自启 (Auto Launch)】与【静默启动】，省去每次开机手动运行的繁琐。

!

Windows 核心避坑：关闭软件后打不开网页怎么办？

很多用户直接关闭软件或非正常关机后，出现“电脑连着网但国内网页全部打不开”的故障。原因是系统代理端口残留未释放。
解决方法：按 Win + i 打开系统设置 > 点击【网络和 Internet】>【代理】> 找到“使用代理服务器”，将其手动关闭即可立即恢复。

MAC TUTORIAL

macOS 苹果电脑客户端配置教程

M系列 / Intel 芯片 原生态体验

macOS 系统注重权限安全与菜单栏静默运行。推荐使用支持 Apple Silicon 原生架构的 Clash Verge Rev for Mac 或 ClashX Meta。

★ 推荐客户端：Clash Verge Rev (Mac) 轻量备选：ClashX Meta / Sing-box 支持芯片：M1/M2/M3/M4 (arm64) & Intel (x64)
01

按处理器架构下载与安装

下载时必须选准架构：近年的 M1/M2/M3/M4 芯片 Mac 请下载带有 arm64.dmg 或 aarch64 的安装包；老款 Intel 芯片请选择 x64.dmg。打开磁盘镜像后，将应用图标拖动到 Applications（应用程序）文件夹。

02

解决“应用已损坏”或无法验证开发者提示

macOS 对非 App Store 应用拦截较严。如果打开提示“无法打开，因为无法验证开发者”或“已损坏”：
① 打开【系统设置】>【隐私与安全性】，向下滚动到安全性一栏，点击【仍要打开】；
② 或在【终端 (Terminal)】中执行以下命令放行签名：

sudo xattr -r -d com.apple.quarantine /Applications/Clash\ Verge.app
03

导入订阅与定时自动更新

复制机场后台的订阅地址，在软件界面的【订阅】模块粘贴并下载。建议在订阅右键菜单中设置【定时更新】（如每 12 小时或 24 小时更新一次），以确保在机场维护更换节点或域名时本地订阅保持同步。

04

菜单栏操作与出站模式

软件启动后会在 Mac 屏幕顶部状态栏常驻图标。点击图标可随时切换【规则 (Rule)】、【全局 (Global)】或【直连 (Direct)】。点击“设置为系统代理”即可开启翻墙加速。需要测试延迟时，点击“连通性测试”可实时刷新节点延迟数值。

05

安装特权辅助工具 (Helper) 与 TUN 模式

若需要接管 Mac 终端命令（如 git clone、brew install、docker pull 等），必须在客户端设置中安装【特权助手工具 (Helper)】，按系统提示输入 Mac 开机密码确认。授权后即可畅快使用 TUN 虚拟网卡功能。

MOBILE TUTORIAL · IPHONE / IPAD

iOS / iPadOS 苹果手机客户端配置教程

iPhone / iPad 全机型 海外 Apple ID 必读

受苹果区域政策限制，中国大陆区 App Store 无法搜索上架翻墙工具。必须使用非国区（美区/港区/日区）Apple ID 进行下载安装。

★ 行业标准推荐：Shadowrocket (小火箭) 高阶规则神卡：Stash (Clash iOS版) 免费开源：Sing-box (App Store直接下载)
🚨 极重安全警告：绝不能在 iPhone 的【系统设置 > 顶部头像 (iCloud)】处登录他人共享账号！这极易导致设备被恶意锁机勒索或个人隐私通讯录被上传！必须且只能在【App Store】内部登录！
01

App Store 登录海外 Apple ID 下载客户端

打开 iPhone 自带的 【App Store】，点击右上角个人头像拉到底部退出当前账号；随后输入美区或港区 Apple ID 登录。在搜索框搜索 Shadowrocket 或 Sing-box 进行下载安装。
没有海外账号？可查看本站专属指南：免费海外 Apple ID 共享账号与安全避坑 →

02

一键导入或扫码导入订阅配置

在 Safari 浏览器中登录你的机场后台，找到“一键导入 Shadowrocket”，系统会自动唤起小火箭完成添加；或者手动复制订阅 URL，打开 Shadowrocket 点击右上角「+」号，类型选择【Subscribe】，在 URL 栏粘贴链接并保存。

03

首次连接添加系统 VPN 配置

选择一个延迟测试通过的节点（如香港、台湾专线节点），打开主界面顶部的总连接开关。系统会弹出 “Shadowrocket 想要添加 VPN 配置” 弹窗，点击【允许】，随后验证 Face ID / Touch ID 或输入锁屏密码即完成配置授权。

04

路由分流设置（省流量防冲突）

在 Shadowrocket 主界面下方将【全局路由】选为【配置 (Config)】模式。该模式会自动判断目标网站：微信、淘宝、网银等国内流量走本地直连，ChatGPT、YouTube、Twitter 等海外网站走代理，既不浪费机场流量，也不影响国内 App 速度。

05

开启按需连接与打开应用时自动更新

点击底部【设置】>【订阅】，打开【打开应用时更新】和【自动后台更新】开关；遇到网络不通时，长按主界面订阅名称点击“更新”，即可自动清除失效节点并载入最新可用入口。

ANDROID TUTORIAL

Android 安卓手机客户端配置教程

小米 / 华为 / OPPO / vivo / 三星 防杀后台指南

安卓开放度最高，但国产定制系统的激进后台省电策略常导致“锁屏即断流”。推荐使用兼容器件最广的 v2rayNG 或 Clash Meta for Android。

★ 新手首选推荐：v2rayNG (简单稳定) 分流进阶首选：Clash Meta for Android (CMFA) 新一代协议旗舰：Sing-box for Android
01

正规官方渠道获取 APK 安装包

强烈建议直接从官方 GitHub Releases 仓库或 Google Play 商店下载最新版 APK 安装包（一般选择 arm64-v8a.apk）。坚决避免安装第三方不知名破解网站打包的修改版 APK，防止账号订阅被嗅探窃取。

02

订阅链接导入与节点批量拉取

复制机场订阅后，打开 v2rayNG，点击左上角三横菜单 >【订阅设置】> 点击右上角「+」号添加订阅 > 备注机场名并粘贴订阅地址并保存。返回主界面，点击右上角三点菜单，选择【更新订阅】，全部海外专线节点即刻导入完成。

03

启动连接与 VPN 网络请求确认

在节点列表中点击选中一个节点，点击右下角的圆形 V 标志连接按钮。系统会弹窗提示“网络连接请求 / 网络监控”，点击【确定】允许创建 VPN 服务通道，当按钮变为绿色或彩色时即代表代理成功接管。

04

安卓绝命关键项：电池优化无限制与后台常驻锁

国产手机（MIUI/HyperOS、HarmonyOS、ColorOS、OriginOS）会在锁屏后强制冻结或杀掉代理进程，造成反复断网！
解决 3 步法：
① 长按客户端桌面图标 >【应用信息】>【省电策略】改为【无限制】；
② 在手机多任务后台列表中，找到客户端卡片长按并加锁；
③ 在系统【应用管理】中开启【允许自启动】与【允许后台关联启动】。

05

分应用代理与分流设置

进入客户端设置，确保路由模式设为【绕过局域网及大陆地址】。进入【分应用代理】功能，勾选你真正需要出海的应用（如 Google Play、Telegram、Chrome、Twitter、ChatGPT、海外手游），避免银行、微信等国内 App 被误走海外 IP 触发风控。

全平台通用排障五步法

第一步：检查本地时间与系统时区（最常见错误）

代理协议（如 VMess、VLESS、Trojan 等）采用严格的时间校验机制。如果电脑或手机系统时间与互联网标准北京时间误差超过 60~90 秒，所有节点都会连接失败或持续报握手错误。请开启系统“自动同步网络时间”。

第二步：更新订阅与检查剩余流量

大部分机场节点失联是因为订阅 URL 过期或账号套餐流量已耗尽。登录你的机场后台确认账号处于有效状态，随后在客户端中执行“更新订阅”以同步最新节点服务器地址。

第三步：核对配置路由与 DNS 污染

如果连接显示绿灯且测速有延迟数值，但浏览器就是打不开网页，通常是本地 DNS 缓存污染或浏览器第三方安全插件拦截。尝试在客户端开启 DNS 映射防污染，或临时切换为全局模式对比测试。

第四步：学会查看错误日志 (Log)

遇到报错时无需盲目重装，在客户端的【日志 (Logs)】面板查看红色的报错提示代码（如 connection refused、timeout 或 certificate error），根据提示搜索定位原因。

第五步：保护个人专属订阅凭据

每一个机场订阅链接都内嵌了专属于你个人账号的 Token 访问秘钥。任何时候都不要将完整的订阅链接直接发到公共论坛、微信群或公开 Issue 中，截图求助时务必将订阅 URL 与节点 IP 打码遮挡。

安全红线

订阅地址等同于你的数字资产通行证，私自泄露可能导致流量被他人盗用甚至账号封禁。

客户端使用高频疑问

先确认本地 WiFi 或移动网络正常连接；接着检查系统时间是否精准到秒（误差超 90 秒必断连）；然后回到机场后台确认套餐未过期且流量有剩余；最后在客户端右键更新订阅，切换 2~3 个不同国家节点测试。
因为你开启了【全局 (Global)】模式，导致所有国内流量全跑去了境外机房绕了一大圈。请将客户端的路由模式调整为【规则 (Rule)】或【配置 (Config)】，这样国内 App 走原生网络直连，海外网站才走专线加速。
